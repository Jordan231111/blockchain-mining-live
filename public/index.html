3 · What am I looking at?

  1. Hash = SHA-256 fingerprint of index + time + data + previousHash + nonce.
  2. Mining = trying nonce = 0,1,2… until the hash starts with N zeroes. That's it. That's proof-of-work.
  3. Chaining = each block stores the previous block's hash. Edit any old block and every link after it breaks.
  4. Live = the server streams mine:progress events over socket.io so you watch the search in real time.
